# Nisha & Thushar — Cinematic South Indian Wedding Invitation

A mobile-friendly, tap-to-reveal wedding website with an animated five-part opening story, traditional styling, photo moments, wedding details, maps, sharing and blessings.

## Publish on GitHub Pages (Android Chrome)

1. Extract this ZIP using your phone's Files app.
2. Open https://github.com/Naveen060798/wedding-invitation in Chrome (turn on Desktop site if necessary).
3. In the repository root, replace `index.html` with the new `index.html` from this ZIP. If the GitHub upload interface does not replace files, delete the old file first and commit, then upload the new one.
4. Open the `images` folder in GitHub, choose **Add file → Upload files**, and upload `sunset.jpg`, `candid.jpg`, `together.jpg` from this ZIP. Do not rename them.
5. Commit changes. GitHub Pages should automatically redeploy if previously configured. Visit https://naveen060798.github.io/wedding-invitation/ and refresh after a few minutes.

Do not upload the ZIP itself as the website. Keep `index.html` at the repository root and images inside `images/`.

## Notes

This design is an original implementation inspired by a cinematic wedding-invitation flow, not a copy of another site's source or assets. The opening has a Skip Intro button. Music is not auto-played. All content runs on static GitHub Pages.

## Live wedding countdown
The hero now displays a live days/hours/minutes/seconds countdown to 22 November 2026 at 6:30 AM IST (Asia/Kolkata), in addition to the countdown section further down the page. The countdown works automatically for visitors in any time zone and shows a wedding-day message once the time has passed.


## Sound and music
This edition includes an original, synthesized South Indian-inspired instrumental loop in `audio/wedding-instrumental.mp3` (flute-like melody, plucked strings, drone) and gentle synthesized temple-bell/chime sound effects. It is not a recorded nadaswaram/thavil performance. Sound starts only after the guest taps an invitation button or Music on, and can be muted with the bottom-left toggle. Upload the complete `audio` folder along with `images` and `index.html`.
